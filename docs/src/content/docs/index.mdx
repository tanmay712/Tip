## What is Crypto?

Crypto is a modern Discord crypto tipping bot that lets you send, rain, and airdrop tokens across nine networks — instantly, with no network fees for internal transfers.

<CardGrid stagger>
  <Card title="Instant Tips" icon="rocket">

  </Card>
  <Card title="9 Networks" icon="puzzle">

  </Card>
  <Card title="Testnet Ready" icon="setting">
